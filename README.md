# 🛡️ Mobile Security Inspector

### Android Security Assessment & Auditing Tool

**Inspect. Assess. Identify. Secure.**

Mobile Security Inspector is a Python-based desktop application designed to assess Android device security through Android Debug Bridge (ADB).

## ✨ Features

- 📱 Android USB device detection
- 🔍 Automated security assessment
- 🔐 Encryption and Verified Boot checks
- 🛡️ SELinux and bootloader status inspection
- 📅 Android security patch inspection
- 📦 Installed application inventory
- ⚠️ Security findings and risk classification
- 📊 Security scoring
- 📄 Professional PDF report generation
- 📂 Existing PDF security report analysis
- 🛠️ Automated dependency and tool installation
- 🎨 Animated cybersecurity-themed GUI

## ⚙️ Technology Stack

- Python
- Tkinter
- Android Debug Bridge (ADB)
- ReportLab
- pypdf

## 💻 Requirements

- Python 3.10+
- macOS, Windows, or Linux
- Android device with USB Debugging enabled
- Android Platform Tools (ADB)

## 🚀 How to Run

**1. Download the project**

Download the repository from GitHub and extract the project folder.

**2. Install dependencies**

Install the required Python libraries listed in `requirements.txt`.

**3. Install Android Platform Tools**

Install ADB and ensure it is accessible from your system. The application also provides a tool installation option on supported macOS systems.

**4. Connect your Android device**

- Enable Developer Options.
- Enable USB Debugging.
- Connect your phone using a USB data cable.
- Accept the USB debugging authorization prompt.

**5. Launch the application**

Open the project folder and run `mobile_security_inspector.py` using Python 3.10 or later.

**6. Start assessment**

Detect your connected device, run the security assessment, review findings, and generate your PDF report.

## 📊 Assessment Results

- **PASS** – Meets assessment criteria
- **FAIL** – Does not meet assessment criteria
- **WARNING** – Potential security concern
- **NOT TESTED** – Unable to complete the check

## 🔒 Security & Disclaimer

This tool is intended for authorized security assessments and educational purposes. It performs baseline security posture checks and does not guarantee detection of every vulnerability.

It is not a replacement for comprehensive mobile penetration testing, malware analysis, or professional security auditing.
